## Every change follows this iteration loop (docs/WORKFLOW.md has the commands)

1. **Train 1 fold first, one architecture** — `bash scripts/vast/train.sh <config> 0 [overrides]`. Compare with the
   current best's fold 0 (EXP-024 dense: OOF 0.8745, gold-58 0.9037). Gate: continue only if fold-0 OOF ≥ best − 0.003 and
   gold-58 did not drop by > ~0.02; otherwise record as NEGATIVE and go to step 5.
2. **Submit 1 fold and the 5-fold ensemble** — `scripts/vast/submit.sh EXP-NNN "<msg>" <ckpts>` for fold 0, then train
   folds 1-4 and submit all 5 (optionally a blend with the current best). Keep one submission/day spare.
   Check the inference time budget first (docs/WORKFLOW.md): stream-mode inference preprocesses ~1,300 test
   studies in ~7 min; EXP-012 (5 × EfficientNet-B0) scored in ~11 min vs the 9 h limit — keep a full run under ~3 h.
   Benchmark new architectures with scripts/bench_inference.py (rsna-knee-bench notebook).
3. **Update results and CV–LB** — `python scripts/track.py lb`, `python scripts/track.py add EXP-NNN --outputs
   runs/EXP-NNN`; check `experiments/EXPERIMENTS.md → CV vs LB`; update the "Current best" table in README.md.
4. **Upload models for backup** — copy the box's `models/` to `runs/EXP-NNN/`, then
   `python scripts/upload_models.py --model <kaggle-model-slug> --exp EXP-NNN runs/EXP-NNN/models/<exp>/fold*.pt`
   (one Kaggle Model per architecture, one variation per fold). Destroy the vast.ai instance afterwards.
5. **Report the iteration and what to do next** — `experiments/reports/ITER-NN_<date>.md` from `TEMPLATE.md`;
   end the turn with a short summary: result vs current best, CV–LB reading, keep/drop, ranked next steps, cost.

## Rules
* Experiment ids `EXP-NNN` are global, never reused, and prefix every Kaggle submission message (LB is matched by it).
* Ask before renting GPUs / spending money or submissions beyond what the user asked for; destroy instances when done.
* Never compare a pseudo-label run's `val_auc_report` with a teacher's: score OOF against `models/oof/report_targets.csv`.
* Single-fold OOF values are on different studies per fold — compare experiments on the same fold or on pooled 5-fold OOF.
* One fold split for all runs: `configs/folds_5.csv` (58 gold studies = fold -1, never trained on).
* Notebooks are generated by `submission/build_kernels.py` — never edit them on kaggle.com. Refresh the code dataset
  with `KAGGLE_BIN=kaggle bash scripts/upload_code.sh "msg"` after code changes that Kaggle/vast runs need.
* Run `pytest -m "not slow"` (and `pytest -m slow` for pipeline changes) before committing code.
